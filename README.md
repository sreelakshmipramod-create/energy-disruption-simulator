  Energy Supply Disruption Simulator (PS02)

An interactive, web-based decision-support engine developed for the Ministry of Power / Central Electricity Authority** to model and evaluate critical infrastructure failures across energy supply networks.
  Key Features
- **Interactive Graph Canvas:** Single-click node disabling (Ports, Refineries, Transmission Hubs) powered by Vis.js topology maps.
- **Dynamic Blast Radius Engine:** Instant calculation of network supply flow deficits, demand deficits, and affected cities.
- **Alternative Routing & Cost Ranking:** Automatically ranks backup transit routes sorted by added per-unit costs (₹/MWh) and transmission delays.
- **Pre-loaded Scenarios:** One-click disruption scenarios including "Mundra Port Strike" and "Northern Substation Failure".
- **Transparent Assumptions:** Real-time visibility into capacity allocations, shortage rules, and transport cost penalties.

 Built With
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Graph Engine:** Vis.js Network
